# Electric Menu Frontend

## Folder Structure

```
├── node_modules
│
├── public
│   └── (static files)
│
├── src
│   ├── assets
│   │   └── (images, icons, dll)
│   │
│   ├── components
│   │   ├── admin_components
│   │   ├── public_components
│   │   └── user_components
│   │       └── user_skeleton_component
│   │
│   ├── pages
│   │   ├── admin_page
│   │   ├── public_page
│   │   └── user_page
│   │
│   └── services
│       └── (API service / logic komunikasi backend)
│
└── package.json
```
